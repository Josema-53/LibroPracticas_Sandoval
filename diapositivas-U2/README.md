# Diapositivas U2 · Tema 2.1 — Actividades en clase

Actividades de las diapositivas «Unidad 2 · UI basada en componentes reutilizables con React»
(tema 2.1, secciones 02-01 a 03-07 del libro). Cada carpeta tiene el código de la actividad y un
`RESPUESTAS.md` con lo que se hizo, la lista **Verifica** y la respuesta a **Responde**.

> En estas versiones el segundo sabor es **Naranjilla** (en las prácticas del libro es Pistacho).

Las páginas `.html` se abren con doble clic (React y Babel llegan por CDN, hace falta internet).
Los proyectos de Vite se ejecutan con `npm install` y `npm run dev` dentro de su carpeta.
